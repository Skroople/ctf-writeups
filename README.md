# CTF Writeups

Short writeups for CTF rooms and machines I solve while learning offensive security.
Each writeup covers the path I took, the commands that mattered, and **why** each step worked.

## Rules I follow

- **TryHackMe**: writeups for rooms I've completed. Flags are redacted (`THM{REDACTED}`) so the room stays worth doing.
- **HackTheBox**: only **retired** machines, as required by HTB's terms.
- Everything here was done on the platform's own lab targets. Don't use these techniques against systems you don't own or aren't explicitly authorized to test.
